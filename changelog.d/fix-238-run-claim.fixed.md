- Two deliveries of one generation job no longer run it at the same time. The transport hands a message out again while its first delivery still runs and after a worker died; the first run now claims the job, and every later status, review and artifact write of a run is bound to that claim. A second delivery while the first run is alive writes nothing and comes back after 15 minutes; after a dead worker it takes the job over. A PDF job's source review and its ingestion now read the same file even when the reference is edited in between ([#238](https://github.com/netresearch/t3x-nr-repurpose/issues/238)).
